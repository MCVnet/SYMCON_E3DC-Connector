# SYMCON E3DC Connector

Leseversion 0.3 für IP-Symcon 9.0. Liest E3/DC one als separate Instanzen und zeigt am Farmmaster die verfügbaren efy-Wallbox-Slots an. Mit konfigurierten Leistungsmessern werden Farmverbrauch und Wärmepumpe getrennt ausgewiesen.
